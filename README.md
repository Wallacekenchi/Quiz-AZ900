# 🚀 Azure AZ-900 Quiz - IA Powered Simulator

Simulador interativo para quem está se preparando para a certificação **Microsoft Azure Fundamentals (AZ-900)**.

Desenvolvido com **Python + Kivy + Inteligência Artificial Generativa**, o objetivo não é só testar — é **ensinar de verdade**.

---

## 🌟 Diferenciais do Projeto

Este não é apenas mais um quiz.

Aqui o foco é aprendizado real:

- ✅ **Feedback Instantâneo**  
  Respostas corretas e incorretas com explicações claras

- 🤖 **Gamificação com IA**  
  Assets visuais (troféus, gifs, ícones) gerados com IA

- 📊 **Análise de Desempenho**  
  Resultado dividido por categorias:
  - Infraestrutura  
  - Segurança  
  - Governança  
  - IA  

- 🔁 **Sistema de Revisão de Erros**  
  Revise somente as questões erradas e aprenda com elas

---

## 🛠️ Tecnologias Utilizadas

### 💻 Software & Código

- **Python + Kivy**
  - Interface gráfica moderna
  - Responsiva e dinâmica

- **Arquitetura**
  - Carregamento dinâmico via `questions.txt`
  - Uso de `resource_path` para assets

---

### 🎨 Creative AI (Generative Stack)

- **Gemini (Nano Banana 2)**
  - Criação da identidade visual

- **PixVerse**
  - Geração de GIFs animados (acerto/erro)

- **Otimização de mídia**
  - Assets leves para manter performance
